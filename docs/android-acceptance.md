# Android P1 验收

日期：2026-09-12。范围依据 [V2 产品第 10 节](product-V2.md#10-p1-范围与验收)。Android 工程独立位于 `app/android/`；既有 iOS 文件保留，其测试结果不计入此表。

## 当前状态

Android MVP 已有可安装 APK，并在生产隔离项目完成模拟器主路径验收；物理设备与自动处理链路仍未通过。上传先提交 File，再以客户端 UUID 提交 note；回顾读取 daily-review State。以下预期保留为完整验收边界，实际结果单独记录。

目标用户是跨 AI 对话推进项目的个人用户；任务是随手记下语音，随后在新对话和每日回顾中使用。主要风险是媒体虽已采集，仍在同步、权限或处理边界丢失、传错账户，或衍生结论失去依据。

## 材料与预期

使用隔离测试账户和独立项目，不使用私人环境录音。预先准备短测试语音：“预算调整为三万元，优先上线移动端，交付时间仍待确认。”保留原始字节、实际时长、MIME 和 SHA-256。

| 场景 | 必须观察到的结果 |
|---|---|
| 首次 HTTPS 登录 | 默认“我的记录”归当前用户所有，且只有当前用户一个成员；不自动选择共享项目 |
| 拒绝麦克风 | 解释所需权限，未开始录音，不创建虚假的已保存文件或成功队列项；其余已有记录仍可查看 |
| 正常开始、暂停、继续、结束 | 页面与前台服务通知状态相符；结束后无需另按上传；先落本机，再收到服务端回执后标为同步 |
| 拍照与选择文件 | 按 V2 第 9.1 节进入相同的 File → UUID note 队列；取消选择不产生伪记录；可查看支持的原始媒体，不声称执行了图片分析 |
| 服务端确认 | App 本机原始文件与认证下载的字节、大小、SHA-256 一致；先上传 File，再提交 UUID note，event 的 project、actor、source 与 UUID 正确 |
| 断网结束并重开 | 文件与固定输入仍在；网络恢复且系统允许运行时自动补传；不能把重新打开解释为重新录制 |
| 请求已提交但响应丢失 | 以原事件 UUID、文件及规范化输入重试；File 按项目与 SHA-256 去重，Event 按项目与 UUID 去重；未收到有效回执前不标为已同步 |
| 录音中断或进程终止 | 重开后提示真实存在的可恢复片段；缺失、空文件不能称为已保存；中断片段经用户明确重试才上传 |
| 登录过期及换账户 | 待传媒体保留并归原 endpoint/account/project；新账户不能读取或自动上传旧账户队列；原账户重新登录后恢复 |
| 锁屏和后台 | Android 允许的录音通过麦克风前台服务持续，通知能结束；后台上传按系统实际调度运行，强制停止后不承诺自动唤醒 |
| 转录处理失败 | 仍可访问已同步的原始媒体；只显示真实插件处理状态，手动重跑的新 derived generation 与旧结果可区分 |
| 查看每日回顾 | 读取 daily-review 日期 State；来源能回到原始或衍生记录；建议与事实分开；展示版本及覆盖范围，不以旧 inbox 代替 |
| 原始来源播放 | 从认证接口读取，先核验大小和哈希；账户/项目变化后旧异步结果不能更新新页面或继续错误播放 |
| 多语言与无障碍 | en、zh、ms、hi 的登录、录音、队列、回顾和错误状态可发现且可读；大字号下关键动作可操作 |

## 与既有后端证据连接

Android 原始媒体进入 V2 `audio-transcribe` 插件，真实 processor host 产生 derived 转录，再由 project-brief 发布 State。新 MCP 对话应回答预算三万元、优先移动端、交付时间未知，并引用原始媒体/转录。包含“旧预算五万元”“未接受的上线建议”“来源不明的冲突”时，仍应区分更新、建议和不确定性。定时回顾须在到点前启动调度等待，实际发布 daily-review 日期 State；人工调用不是定时证明。

旧版后端、网页、runner 和 MCP 的证据只证明对应旧实现。V2 数据与接口已改变，Android 验收必须核对同一条采集记录从本机文件、File、UUID Event、转录、State、MCP 引用到手机回顾的对应关系。

## 证据分级

- 构建和单元测试：证明对应代码可构建或受测逻辑成立。
- 模拟器：证明其特定系统镜像、权限和网络条件下的交互及持久化结果。静音录制只能证明录音容器、队列及字节链路，不能证明转录质量。
- Android 真机：补齐真实麦克风、锁屏、来电/音频中断、厂商电池策略和后台恢复。未连接真机时必须保留未验收状态。
- 发布：另行记录实际 APK 签名、分发和服务端发布环境；本轮本地验证不意味着已发布。

调试 TLS 仅信任隔离测试 CA，发行构建保持正常主机名与证书校验。测试密码和令牌不得写入此文档、仓库或截图；含凭据的临时配置在验收结束后清除。
